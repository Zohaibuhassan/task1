# Game Code Agent

## Overview

This project implements a code agent that generates a playable game with a user interface based on the given requirements.

The repository contains the implementation of the code agent, architecture documentation, and supporting files required to understand and run the project.

The main objective of this project is to demonstrate how an automated code agent can generate a complete game project and produce a functional game with UI.

---

## Features

* Automated game/project generation
* Code-agent based workflow
* Generated game with user interface
* Structured project generation
* Architecture documentation
* Automated project setup through Python

# Quick Start

## 1. Clone the Repository

Clone the GitHub repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Then enter the project directory:

```bash
cd chinaAssigment
```

---

## 2. Create a Python Virtual Environment

It is recommended to use a virtual environment.

On Windows:

```powershell
python -m venv venv
```

Activate the environment:

```powershell
venv\Scripts\activate
```

After activation, your terminal should show something similar to:

```text
(venv) PS C:\...\chinaAssigment>
```

---

## 3. Install Required Dependencies

If a `requirements.txt` file is included in the repository, install the dependencies using:

```bash
pip install -r requirements.txt
```

If the project does not contain a `requirements.txt` file, install the Python packages required by `generate_project.py` according to the imports used in the script.

---

# Running the Code Agent

The main code-agent script is:

```text
generate_project.py
```

Run it from the project root directory:

```bash
python generate_project.py
```

The script will execute the project-generation workflow and generate the required game/project files.

---

# Generated Game

After the code agent finishes execution, locate the generated project in the output directory created by the script.

The generated project contains the game implementation and its user interface.

Open the generated project using the appropriate development environment and follow the generated project's run instructions.

> **Note:** The exact command for running the generated game depends on the project structure and framework generated by the agent.

# Troubleshooting

## Python command is not recognized

Make sure Python is installed and added to the system PATH.

Check the installation with:

```bash
python --version
```

---

## Virtual environment does not activate

On Windows PowerShell, run:

```powershell
venv\Scripts\Activate.ps1
```

If PowerShell prevents script execution, you may need to adjust the PowerShell execution policy or activate the environment using Command Prompt:

```cmd
venv\Scripts\activate.bat
```

---

## Generated game does not start

First make sure that:

1. The code agent completed successfully.
2. All generated files are present.
3. Required dependencies are installed.
4. You are running the game from the generated project's directory.
5. You are following the run instructions for the generated project's framework.
